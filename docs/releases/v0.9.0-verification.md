## Known limits and stop point

The Mac build is ad-hoc signed, not Apple-notarized; Windows binaries are unsigned. Six moderate development packaging-chain audit findings remain documented in [the bounded audit](../audit-0.9.0.md), with no high/critical findings. Stream availability remains time-dependent; successful decoding is separate from RF reception or audible listening. See [the test log](../smoke-test.md) for actual candidate coverage and native evidence boundaries.

GitHub About is prepared for manual owner insertion. Website/landing page is deferred. Placeholder centering/proportions are queued for the next agreed block. No player code was changed to address that cosmetic issue during release. This completes the authorized release block; further features require a separate development discussion.
